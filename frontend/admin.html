OTP Verification Mode
Both Environments
otp_mode - Current: —
otp_bypass_code - Current: —
Modes:
- 🔒 Strict Mode: OTP required for registration, login, and password reset. No bypass code. Use for production security.
- 🧪 Testing Mode: OTP required for all flows, but bypass code works. OTP is shown in frontend and logs. Use for local development and AI testing.
- 🔧 Bypass Mode: OTP required for all flows, bypass code works. OTP is shown in logs/API but NOT in frontend. Use for backend debugging.
- 🔐 Bypass Only Mode: OTP required for all flows, bypass code works. OTP is NOT shown in frontend or logs (secret). Use for secure testing.
- ⚠️ Disabled: No OTP required for registration and login. Password reset will be disabled because it requires OTP verification. Not recommended for security. Applies to both environments.
