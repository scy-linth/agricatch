# AgriCatch

Production-ready Agricultural E-Commerce Platform

---

## Overview

AgriCatch connects customers directly with verified farmers through a secure,
scalable, and maintainable e-commerce platform.

Supported business workflows include:

- Available Products
- Hybrid Pre-order
- Wishlist
- Cart
- Checkout
- Orders
- Messaging
- Notifications
- Reviews
- Administration

---

# Getting Started

Before making changes:

1. Read `.windsurfrules`
2. Read `AGENTS.md`
3. Review relevant documentation under `docs/`
4. Inspect the repository
5. Begin implementation

Repository implementation is always the source of truth.
