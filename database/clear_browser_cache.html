🧹 Clear Browser Cache for Orders

Instructions:
  1. Make sure you've already run the database clear script: node database/clear_orders.js
  2. Click the button below to clear browser cache
  3. Refresh your browser pages (F5) to see the changes

Manual Method (Browser Console)

Alternatively, open your browser console (F12) and run:

// Clear localStorage (preserving token) const token = localStorage.getItem('token'); localStorage.clear(); if (token) localStorage.setItem('token', token); // Clear sessionStorage sessionStorage.clear(); // Reload page location.reload();
