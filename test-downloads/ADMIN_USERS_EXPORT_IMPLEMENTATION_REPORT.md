## Endpoints Added

### GET /api/admin/users/export.xlsx

**Query Parameters**:
- `search` (optional): Search by username, email, full name, first name, last name
- `role` (optional): Filter by role (customer, farmer, admin, super_admin)
- `status` (optional): Filter by status (active, disabled, suspended)
- `verification` (optional): Filter by verification status (verified, unverified, pending)

**Access Control**:
- Requires admin authentication (reuses existing `requireAdmin` middleware)
- Super admins can see all roles including admins and super_admins
- Regular admins can only see customers and farmers

**Response**:
- Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet
- Content-Disposition: attachment; filename="Admin_[Role]_Report_YYYY-MM-DD.xlsx"
- Returns Excel workbook buffer

## Services Added

### getAdminUsers(pool, options)

**Purpose**: Fetch filtered admin users with pagination support

**Parameters**:
- `pool`: Database connection pool
- `options`: Query options (search, role, status, verification, page, limit, includeCount, userRole)

**Returns**: `{ users, total, page, limit }`

**SQL Logic**:
- Dynamically checks available columns using `getTableColumns()`
- Filters by search across multiple fields (username, email, full_name, first_name, last_name)
- Filters by role (with authorization check)
- Filters by status (active/disabled/suspended)
- Filters by verification status
- Supports pagination
- Orders by created_at DESC

**Reused Components**:
- Same pagination pattern as `getAdminOrders()`
- Same column checking pattern as Admin Users page
